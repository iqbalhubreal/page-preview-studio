Page Preview Studio
==================

Files:
- index.html: page structure and external library/import-map references
- styles.css: all page styling
- js/app.js: Three.js scene, PDF page handling, animation, camera, recording, audio, and UI logic

Run:
Because the app uses JavaScript modules and CDN imports, open this folder through a local web server
(for example, VS Code Live Server) rather than opening index.html directly as a file.
Keep the folder structure intact so js/app.js can be found.
